# Assessment 3.3: Non-Linear Data Structure

Binary tree and graph built from the last name **BACULI**, with BFS and DFS traversals.

| File | Description |
|---|---|
| `binary_tree.py` | Binary tree (filled level by level) with BFS and DFS |
| `graph.py` | Graph (adjacency list) with BFS and DFS |

## Run

```
python binary_tree.py
python graph.py
```

## Expected output

Binary tree: BFS `B - A - C - U - L - I`, DFS `B - A - U - L - C - I`

Graph: BFS `B - A - C - L - U - I`, DFS `B - A - L - C - I - U`
